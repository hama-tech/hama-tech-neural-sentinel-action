# Contributing to Neural Sentinel Action

Thank you for your interest in contributing to Neural Sentinel! We welcome contributions to help make AI security more accessible and robust.

## How to Contribute
1. **Fork the Repository**: Create your own fork on GitHub.
2. **Create a Branch**: Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
3. **Make Your Changes**: Implement your changes, ensuring they align with the project's goals.
4. **Test Your Changes**: Run the existing test suite and add new tests if you are adding new detection rules.
5. **Submit a Pull Request**: Open a PR against the `main` branch with a clear description of the changes.

## Coding Standards
- **Python**: Follow PEP 8 guidelines. We use `flake8` and `bandit` for linting and security checks.
- **Bash**: Follow standard Bash best practices. We use `shellcheck` to catch common mistakes.
- **Commits**: Write clear, descriptive commit messages.

## Reporting Bugs
If you find a bug, please open an issue on GitHub using the bug report template. Provide steps to reproduce the issue.

## Security Vulnerabilities
If you discover a security vulnerability, please **do not** open a public issue. Report it privately via GitHub Security Advisories or by emailing mohamed@neuralsentinel.online.

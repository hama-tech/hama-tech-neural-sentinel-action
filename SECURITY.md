# Security Policy

## Reporting a Vulnerability
The security of Neural Sentinel is a top priority. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via:
1. GitHub's private [Security Advisories](https://github.com/hama-tech/hama-tech-neural-sentinel-action/security/advisories) feature.
2. Email: mohamed@neuralsentinel.online

You should receive an initial response within 14 days. We will work with you to understand the issue and coordinate a fix and public disclosure.

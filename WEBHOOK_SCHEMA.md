# Neural Sentinel GRC Automation Webhook Schema

This document details the outbound webhook payload generated by the **Neural Sentinel Enterprise Docker Appliance** when the **GRC Automation Add-on** is active.

## ⚠️ Prerequisites & Licensing
This webhook is **only** triggered for accounts with an active License + GRC Add-on

*Note: Trial and base-tier licenses do not have webhook capabilities enabled.*

## 🔒 Security & Authentication
Every payload is cryptographically signed to prevent tampering. Your receiving endpoint must verify the signature:
- **Header:** `X-NeuralSentinel-Signature`
- **Algorithm:** HMAC-SHA256
- **Secret:** Provided by the customer during Docker execution (`NS_WEBHOOK_SECRET`)
